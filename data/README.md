# Data Directory

Original source documents for the Class 4 Catechism content. The curriculum has already been extracted into `src/data/`; these files are kept for reference and are not deployed.

## Directory Structure
- `input/textbook/`: the 15 textbook chapters, `chapter-01.pdf` to `chapter-15.pdf`.
- `input/question-papers/`: the five past semester exam papers, named by the paper id used in `src/data/examPapersData.js`:

  | File | Paper |
  | :--- | :--- |
  | `2023_s1.pdf` | First Semester Examination 2023-24 |
  | `2023_s2.pdf` | Second Semester Examination 2023-24 |
  | `2024_s1.pdf` | First Semester Examination 2024-25 |
  | `2025_s1.pdf` | First Semester Examination 2025-26 |
  | `2025_s2.pdf` | Second Semester Examination 2025-26 |

- `input/multi-agent-design.pdf`: multi-agent design notes behind the learning console.
