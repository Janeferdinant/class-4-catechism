# Data Directory

This directory stores raw input datasets and generated outputs for the Class 4 Catechism application.

## Directory Structure
- `input/`: Contains original source documents, including:
  - 15 textbook chapter scans (`chapter1.pdf` through `chapter15.pdf`) from Diocese of Mananthavady Class 4 Catechism.
  - Multi-agent architecture specification (`multi  agent.pdf`).
  - 5 historical examination papers (`2023-2025` First and Second Semester exam papers).
- `output/`: Designated folder for generated transcripts, exam evaluation reports, and synthetic assets.
